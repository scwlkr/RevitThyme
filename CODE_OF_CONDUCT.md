# Code of conduct

RevitThyme welcomes people with different backgrounds and experience. Be respectful, patient and specific. Critique ideas and code without attacking people. Credit others' work, accept constructive feedback and keep discussions relevant.

Harassment, discrimination, threats, sexualized conduct, deliberate intimidation, doxxing and publication of private information are unacceptable. Do not post private models, credentials or personal data without permission.

This applies in project issues, pull requests and other project-managed spaces, and when representing the project publicly.

## Report and resolve

Contact maintainer Shane Walker through a contact channel listed on [the GitHub profile](https://github.com/scwlkr). Include a link or description and explain any privacy concerns; do not repeat sensitive information in a public issue. For a software vulnerability, use the [security policy](SECURITY.md).

The maintainer will review context and may request a correction, remove content, temporarily restrict participation or permanently exclude a participant. Responses should be proportionate to impact and repeated behavior. Reports are handled privately where practical; absolute confidentiality and response deadlines cannot be promised.
