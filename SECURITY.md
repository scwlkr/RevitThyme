# Security

Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately through their GitHub profile. Never attach credentials or private models to public issues.

The supported release line is 0.2.x. RevitThyme adds read-only named Routes on the existing loopback server. It provides no remote authentication. Keep pyRevit Routes on 127.0.0.1 and never forward port 48884.

SHA-256 hashes check integrity, not an unknown distributor's identity. Obtain releases from this repository. The installer preserves settings, refuses unmanaged/modified extension files, retains recoverable backups and blocks updates/uninstall while Revit runs.
