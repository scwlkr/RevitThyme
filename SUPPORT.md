# Support

Start with [first steps](docs/QUICK-START.md), [installation](docs/INSTALLATION.md) and [troubleshooting](docs/TROUBLESHOOTING.md). Use `rthyme --help` for installed CLI commands.

## Bugs and questions

Use [GitHub issues](https://github.com/scwlkr/RevitThyme/issues/new/choose) for reproducible bugs, setup questions and documentation problems. Include your toolkit version, affected interface, exact Revit build if relevant, expected/actual behavior and sanitized steps. Use a small public sample where possible. No private tracker account is required.

Do not upload production models, credentials, conversation state or raw captures containing model paths and parameter data. Share only what is needed to reproduce the problem. Security reports belong in [private reporting](SECURITY.md).

## Expectations

This is a pre-1.0 open-source project maintained as availability permits, without a support SLA. Full Revit 2027 is the supported host; other years and Revit LT are unsupported. A report from a different build or computer helps qualification but does not establish support automatically.

For a new tool, explain the workflow and observable result through a feature request. To help resolve a problem, see [contributing](CONTRIBUTING.md).
