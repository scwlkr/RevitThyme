# Troubleshooting

Start with the exact version, process and document. Keep private model paths, parameter values and credentials out of public reports.

## The RevitThyme tab is missing

Confirm full Revit 2027, Windows x64 and .NET 10 Desktop/Core x64 runtimes. Revit LT and other years are unsupported. Installation requires Revit closed normally; a running process retains loaded assemblies until restart. Review setup logs and the [receipt](INSTALLATION.md#installed-files-and-recovery). Do not delete unrelated add-in registrations.

The public installer is unsigned. Verify source/checksum and follow your organization's policy. Local development signing is a separate identity.

## PowerShell cannot find rthyme

Open a new terminal and inspect command precedence:

```powershell
Get-Command rthyme -All
```

Aliases, developer snapshots or earlier machine PATH entries may take precedence. Use the receipt's absolute `global_command` path to identify the installed version. Do not overwrite unrelated PATH entries.

## No session or the wrong document

Confirm Revit is running with the matching add-in. Run `rthyme sessions --json`; normal discovery is `%LOCALAPPDATA%\RevitThyme\sessions`. Development runs have their own folder; use `project.cmd dev-status -RunFolder $run`.

Choose an explicit binding and inspect process start, document and view. Dead/reused processes and incompatible protocols are rejected. Upgrade add-in/CLI/MCP together. A pinned server cannot switch sessions. Never bypass failure by choosing a working model.

## A capture is stale

Model/view changes invalidate captures. Reinspect current values, but form a new edit only after any earlier operation is confirmed complete. Reopening a document creates a new identity.

## An edit timed out or returned Unconfirmed

Do not immediately submit a new write ID. Recover the original through MCP `get_operation` or CLI `get-operation --session ABSOLUTE_FILE --request-id GUID --json`. Inspect native values and request state. A timeout is not proof of rollback. Outcomes are session-retained; keep the session alive during recovery.

## View Range refuses an edit

Refresh in a floor, ceiling or structural plan. Controlling templates block edits. Revit validates plane order and special levels; ceiling plans look upward. More than 100 levels are refused. Plan regions and template editing are outside scope. See [View Range](NATIVE-UTILITIES.md#view-range).

## Room Dimensions has no preview

Use an enclosed rectangular room with four straight basic native walls on the view's level and phase. Linked, curved, slanted or irregular boundaries and split crops are unsupported. A rectangular crop must contain the whole room. Move a blocking tag or adjust clearance/inset; the tool never moves tags. Partial/duplicate/locked dimensions may need manual resolution. See [Room Dimensions](NATIVE-UTILITIES.md#room-dimensions).

## Agent sign-in or model access fails

Connect Codex, complete browser sign-in, then Refresh. A runtime model listing is not an entitlement guarantee. Let Codex own authentication; never post credential files. See [Agent state](AGENT.md#local-state-and-connection).

## Website search is empty during development

Search indexes are generated by a production build. In `website`, run `npm run build`, `npm run check`, then `npm run serve` to test search. Use `npm start` for editing. See [website maintenance](WEBSITE.md).

## Still stuck

Open a [bug report](https://github.com/scwlkr/RevitThyme/issues/new/choose) with interface, toolkit version, exact Revit build when relevant, reproduction, expected/actual behavior and sanitized diagnostics. Prefer a minimal public sample to production models. Report [security issues](../SECURITY.md) privately.
