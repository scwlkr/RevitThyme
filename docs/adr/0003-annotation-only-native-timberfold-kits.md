# Annotation-only native TimberFold kits

Generate review documentation as new drafting views and titleblock-free native sheets in the pinned source document. Import actual-inch CUT DXFs into dedicated view-specific export views; import separate REFERENCE vectors for stock and assembly guides, with native TextNotes carrying exact panel/source/face identities. Export only CUT views to DWG. Deliver a standalone SVG guide as well.

Model DirectShapes can appear in existing building views and would require broad visibility changes. Native detail curves cannot represent every small fabrication edge at physical scale under Revit's ShortCurveTolerance. View-specific CAD retains the canonical geometry without adding model geometry; native closed-contour, scale and layer readback remains mandatory. Editable import-level vectors and native labels/sheets are the supported documentation granularity.

Native assembly-reference imports use a recorded review multiplier of 48. Revit simplified a projected joint corner by about 0.000279 physical inch at multiplier 1; a full-input temporary-document probe at multiplier 48 passed the unchanged absolute native readback gate. Derive separate `native-reference-inputs` DXFs with coordinates multiplied by 48 and inch metadata retained, consume their saved units, use reference View.Scale 48, and multiply native label insertion coordinates by 48. Native text height remains its paper height; sheet placements retain physical paper dimensions. Preserve the original physical guide vectors and SVG. CUT views, cutting DXF/DWG and calibration remain multiplier 1. Receipts record both source/input hashes and the reference transform; verify native geometry, label coordinates and view scales explicitly. Do not raise fabrication or export tolerances to accommodate reference import simplification.

One synchronous TransactionGroup contains all native documentation and reversible export/readback. No transaction crosses an await and the source is never saved automatically. Audit every added element and imported resource; preserve pre-existing element identities, parameters, active view, source geometry and saved-file hashes. VersionGuid alone cannot establish in-session preservation. Require actual single-Undo qualification separately from source checks.

Revit also emits modification notifications for an opaque pre-existing element when creating a drafting view, sheet or viewport, without changing its accessible content. Identify this bookkeeping behavior per run with a controlled drafting-view transaction and checked group rollback. Allow only dynamically observed modified IDs whose runtime type is exactly the base Element class, with no category, owner view, element type or extensible-storage schemas. Require unchanged original identities/content, source view, saved file, open-document inventory and modification state after calibration. Clear calibration notifications only after restoration. During real generation every original content hash must still match; deletion and unexpected modification notifications remain blocking. Record the calibration provenance and eligible IDs in the prepared receipt. No fixture-specific ID or general notification exemption is acceptable.

Flush `native-prepared.json` before assimilation. The background coordinator waits for a definitive native receipt even after cancellation; a confirmed commit wins a late cancellation. Retain `native-receipt.json`, verify output hashes and publish `kit.json` last. Publication failure after commit is Unconfirmed, with NativeCommitted retained; same-ID retry must never repeat native writes. Interrupted runs remain unconfirmed across host restart. Completed kits are rehashed by explicit verification and recovery.

Protocol 7 adds shared generation from a retained preview ID and explicit retained-file verification. Clients cannot submit geometry or output paths. Generation revalidates preview evidence, captures the exact pinned source again, checks its fingerprint and recomputes fabrication/layout before native creation. Status and cancellation retain their separate control channels. Digital verification never implies measured material, kerf or assembly qualification; those remain explicitly outstanding.
