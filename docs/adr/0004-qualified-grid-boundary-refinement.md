# Account explicitly for rounded Boolean intersections

An integer-grid Boolean intersection can move off its original straight edge: clipping the triangle `(0,0),(7,0),(2,5)` at `y=3` produces retained and removed twice-areas totaling 36 instead of the original 35 because the exact intersection `(6/5,3)` rounds to `(1,3)`. Node the affected before-boundary through the shared rounded intersection, keeping original vertices fixed, proving finite-edge distance and projection order within one grid unit, checking topology, and recording the signed exact area adjustment and edge/point provenance separately from material removal; require `original area + adjustment = refined area = retained + removed` exactly. Bound cumulative per-panel geometric adjustment below the accepted physical contour gate and reject unproved cases; retain the immutable source snapshot and strict binary prism/triangle verification, rather than accepting an area epsilon or replacing the bounded grid kernel with a new rational polygon representation.
