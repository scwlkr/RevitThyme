# Separate read-only native kit reconciliation

Reconcile a definitively committed generation using a fresh capture of the same process, session and document, a pre-dispatch input seal bound into the prepared/committed receipts, and current native identities, content, contours, labels and sheets; an independent recovery run retains its own receipt and final manifest while the original generation, outputs and timings remain unchanged and absent or ambiguous documentation is never recreated automatically.

This permits recovery after a final-manifest publication failure without repeating native writes or mistaking file verification for current model presence. A different current active view and a later manual save are allowed only while current source content/geometry and read-only preservation checks pass; legacy unsealed kits and missing definitive commit receipts remain unconfirmed.
