# Issue tracker

Use Linear team **WLKR LABS** (`WLK`), project [RevitThyme](https://linear.app/wlkr-labs/project/revitthyme-fea9af3040c9). Search before creating duplicate work. Use connected Linear tools; retain issue names and URLs in local evidence. Specs may be parent issues or linked Linear documents. Each implementation ticket states its acceptance criteria and native blocking relationships. Work blockers first. Preserve local source and verification evidence; an issue is Done only after verified acceptance and default-branch landing. External pull requests are not an incoming triage surface by default.

## Wayfinding operations

Create one parent map issue labelled `wayfinder:map`; children use `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling` or `wayfinder:task`. Create native parent and blocked-by relationships in a second pass after IDs exist. Create missing labels only when first needed. Claim a frontier ticket by assigning the owner before work. The frontier contains open, unblocked and unclaimed children, ordered oldest first. Resolve decisions in a comment with evidence links, close the decision ticket, and append a named pointer to the map's Decisions so far. Decision closure is distinct from implementation delivery. Refer to issues by their linked title.
