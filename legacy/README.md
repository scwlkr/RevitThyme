# Historical source

`pre-foundation` preserves the implementation superseded by the 2026-10-14 C# plan. Its code, lockfiles, developer tools, docs and qualification records are retained for later migration and reproduction. They are excluded from the active C# solution, public CI and package.

Historical paths inside this tree predate the move. Private build caches moved with their source folders and remain ignored. Existing root `artifacts`, `runs` and `packages`, installed bundles and external TimberFold were preserved. See [migration](../docs/MIGRATION.md).
