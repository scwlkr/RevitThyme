Install

  1. Verify the ZIP

    Compare this hash with the checksum file.

    Get-FileHash .\RevitThyme-0.2.0.zip -Algorithm SHA256

  2. Extract and install

    Open PowerShell in the extracted folder.

    & .\scripts\install.ps1

  3. Start Revit

    Open RevitThyme → Suite Status. Use normal startup; close Revit before updates.
