THREE STEPS TO GET GOING

From ZIP to ribbon.

  1. Verify your download

    Compare the ZIP's SHA-256 with the checksum file.

    Get-FileHash .\RevitThyme-0.2.0.zip -Algorithm SHA256

  2. Extract and install

    Extract to a new folder. Open ordinary PowerShell there.

    & .\scripts\install.ps1

  3. Start Revit normally

    On your next normal start, open RevitThyme → Suite Status. Close Revit yourself before upgrades or uninstalling.

Before you install

Install licensed Revit and pyRevit independently. The tested development host uses Revit 2027.2 (27.2.0.39) and pyRevit 6.5.5.26237+2044.

Other builds, repeated Reload stability, and second-computer behavior remain unverified. Prefer normal Revit startup.

TimberFold is separate. This ZIP includes inspection, with generation remaining in the existing TimberFold command.
